How this works

The interface is in English. Questions, column names, SQL, and raw model replies stay in their original language. FTS5 searches column names and notes for keywords and adds those schema clues to the model.

SQLite EXPLAIN checks syntax and table and column names. After SQL runs, you can inspect the result. Correctness is decided only by comparison with the benchmark reference.
